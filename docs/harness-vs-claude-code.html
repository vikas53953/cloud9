Cloud9 next to Claude Code

What we have, what we don't, and where something looks like it works but doesn't. Checked against the code on master (e08ba7f) — which is the exact code installed on your machine right now.

The one-line answer

Cloud9 does not have its own agent brain. It drives the real Claude Code that is already on your computer — so you already have almost all of the harness. What is missing is mostly things Cloud9 switches off, things it never shows you, and one second, much weaker route that takes over the moment you paste an API key into Settings.

Proof: every turn runs the command claude -p --output-format stream-json --verbose --permission-mode dontAsk … as a real program on your PC. Cloud9 writes the instructions, hands them over, and reads back what happened. The thinking, the tool calls, the try-again loop — all of that is Claude Code's, not ours.
