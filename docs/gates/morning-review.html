The one reality check ⚠️

"Connect your Claude subscription" hit an official wall. Anthropic's docs state third-party apps may not offer claude.ai subscription login without prior approval. So Cloud9 ships two credential options per user in Settings: (a) your own Anthropic API key — fully sanctioned, pay-per-use — and (b) a token you generate yourself with claude setup-token (bills to Pro/Max; the policy gray zone is disclosed in-app). Without a credential, agents run in a free demo mode — that's what tonight's QA used, so agent replies in screenshots are canned.
